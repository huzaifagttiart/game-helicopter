# Helicopter Battle 3D

## Files
- `index.html` — page and HUD
- `style.css` — visual styling
- `game.js` — Three.js game logic

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Use the **Live Server** extension and open `index.html`.
   You can also open `index.html` directly in a modern browser, but a local server is more reliable.
4. Internet is required to load Three.js from the CDN.

## Controls
- W / S: move forward / backward
- A / D: strafe left / right
- Left / Right arrows: turn
- Q / E: spin / rotate
- Shift: rise
- Ctrl: descend
- Mouse: aim
- Left click: bullets
- Space: missile
- R: restart

This is a playable 3D starter game using procedural models (not a photorealistic commercial game asset pack). You can later add imported `.glb` helicopter models, sound effects, mobile controls, and a menu.
